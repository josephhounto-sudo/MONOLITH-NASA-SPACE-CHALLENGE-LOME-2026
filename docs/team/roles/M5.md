## M5-1 · Assemblage et tour GO / NO-GO
**Rôle :** M5 (tenu par M1) · **Quand :** 13:30, 17:30, 22:30, dim 10:30, 12:00

**Pourquoi :** Un seul point d'assemblage évite que les travaux se cassent entre eux.

1. Sur GitHub, onglet Pull requests : ouvre chaque PR.
2. Vérifie la liste docs/RELEASE_CHECKLIST.md (V1 à V12).
3. Clique « Merge pull request » si tout est vert ; sinon commente ce qui manque.
4. En local : git checkout main && git pull && python -m pytest -q.
5. Tour de 5 minutes : chacun dit GO ou NO-GO en une phrase.
6. Samedi 22:30 : git tag checkpoint-sat && git push --tags. Dimanche 10:30 : tag freeze.

**Fini quand :** main passe les tests après chaque assemblage.

**Prompt à coller dans Cursor :**
```text
Pour la pull request [nom de la branche], liste les fichiers modifiés et vérifie un par un les points V1 à V12 de docs/RELEASE_CHECKLIST.md. Réponds par un tableau : point, OK ou PROBLÈME, explication en une ligne. Ne fusionne rien.
```
