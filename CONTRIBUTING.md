# How we work (team rules)
1. One branch per task: `m2-capsule`, `m3-nominal`… Never push to `main`.
2. Before pushing: `python -m pytest -q` must pass.
3. Commit message: `M2: what you did`.
4. Open a pull request; M5 merges at checkpoints (13:30, 17:30, 22:30; Sun 10:30, 12:00) after `docs/RELEASE_CHECKLIST.md`.
5. Never commit names, phone numbers, keys, or real personal data. Never write: cause, diagnosis, disease, proves, guaranteed.
6. Contracts change only with M1's approval.
Task cards with exact steps and ready-to-paste prompts: `docs/team/` (French).
